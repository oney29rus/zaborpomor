# Production Environment Checklist — «Заборы Поморья»

Перед запуском на production задайте переменные окружения на хостинге. **Не коммитьте значения секретов в репозиторий.**

## Обязательные переменные (SMTP / заявки)

| Переменная | Назначение |
|------------|------------|
| `SMTP_HOST` | SMTP-сервер (например, `smtp.yandex.ru`) |
| `SMTP_PORT` | Порт SMTP (обычно `465` для SSL или `587` для STARTTLS) |
| `SMTP_USER` | Логин почтового ящика для отправки |
| `SMTP_PASSWORD` | Пароль приложения или SMTP-пароль (**секрет**) |
| `LEADS_EMAIL` | Адрес, на который приходят заявки с сайта |

## Необязательные переменные

| Переменная | Назначение |
|------------|------------|
| `LEADS_EMAIL_FROM` | Отображаемое имя отправителя в письме |
| `NEXT_PUBLIC_YANDEX_METRIKA_ID` | ID счётчика Яндекс Метрики (если не задан — счётчик не загружается) |

## Проверки перед деплоем

- [ ] Файл `.env.local` не попадает в git (`.env*` в `.gitignore`)
- [ ] Нет переменных `NEXT_PUBLIC_*` с SMTP-секретами
- [ ] Production build проходит **без** обязательного наличия SMTP env (сборка не падает)
- [ ] При отсутствии SMTP env API `/api/leads` возвращает **503** с понятным сообщением пользователю, приложение не падает

## Smoke-test после deploy

1. Откройте production-сайт в браузере (инкогнito или с `?utm_source=test&utm_medium=manual`).
2. Перейдите на страницу с формой (главная → калькулятор или блок «Оставить заявку»).
3. Отправьте **одну** тестовую заявку с реальным номером, к которому у вас есть доступ для проверки звонка.
4. Убедитесь, что форма показывает **success state** («Заявка отправлена»).
5. Проверьте почтовый ящик `LEADS_EMAIL` — письмо получено.
6. В письме проверьте: телефон, страницу отправки, город (если был), параметры калькулятора (если отправка из калькулятора).
7. Если заходили с UTM — проверьте, что UTM/yclid/referrer попали в письмо.
8. В DevTools → Network: ответ `/api/leads` содержит только `{ "ok": true }` или сообщение об ошибке — **без** SMTP-паролей, токенов и внутренних env.
9. В DevTools → Sources/Response: нет секретов в JS-бандле (`SMTP_PASSWORD`, пароли приложений).
10. Если задан `NEXT_PUBLIC_YANDEX_METRIKA_ID` — в Network появляется запрос к `mc.yandex.ru`, цели срабатывают при отправке заявки и клике по телефону.

## После получения ID Метрики

1. Создайте счётчик в Яндекс Метрике для `zaborpomor.ru`.
2. Добавьте `NEXT_PUBLIC_YANDEX_METRIKA_ID` на production (только ID, без секретов).
3. Настройте цели в интерфейсе Метрики: `lead_submit`, `calculator_submit`, `phone_click`, `city_click`, `fence_type_click`.
4. Перезапустите приложение / redeploy, чтобы подхватить env.
